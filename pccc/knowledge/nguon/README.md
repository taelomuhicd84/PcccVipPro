# Bản gốc văn bản (nguồn đối chiếu)

Đặt tại đây bản gốc (PDF/DOCX) của Luật, Nghị định, Thông tư, QCVN, TCVN để Claude đối chiếu và nâng nhãn số liệu lên `[BG]`.

Quy ước đặt tên: `<so-hieu>__<ten-ngan>.pdf`, ví dụ:
- `QCVN-06-2022-BXD__an-toan-chay.pdf`
- `QCVN-06-2022-BXD-SD1-2023.pdf`
- `QCVN-10-2025-BCA__trang-bi-phuong-tien.pdf`
- `TCVN-7336-2021__sprinkler.pdf`

Sau khi thêm file: gõ `/pccc-cap-nhat-tri-thuc` để Claude trích điều khoản, cập nhật `pccc/knowledge/*.md` và `pccc/tools/du_lieu_tham_chieu.json`.

Lưu ý: TCVN là tài liệu có bản quyền — chỉ lưu trong repo riêng tư. File lớn nên dùng Git LFS.
