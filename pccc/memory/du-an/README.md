# Bộ nhớ theo dự án

Mỗi dự án một file `<mã-dự-án>.md` (cùng mã với `pccc/du-an/<mã>/`). Ghi nối:

```
- YYYY-MM-DD · [quyết định|giả định đã xác nhận|phản hồi thẩm định|thay đổi thiết kế] · nội dung · nguồn (người/ văn bản)
```

Ví dụ:
- 2026-11-05 · [giả định đã xác nhận] · GĐ-01: chiều cao PCCC 63,5 m (CĐT xác nhận cao độ mặt đường −0,700) · email CĐT
- 2026-11-20 · [phản hồi thẩm định] · Yêu cầu bổ sung sảnh ngăn khói tầng hầm B2 theo SĐ1:2023 · biên bản thẩm định
